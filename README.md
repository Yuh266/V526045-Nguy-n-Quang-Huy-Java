# V526045-Nguy-n-Quang-Huy-Java

Các bài tập Java về mảng và lập trình hướng đối tượng.

- `Slide2_MangSoNguyen.java`: Nhập, xuất và tính tổng mảng số nguyên.
- `Slide2_TongHaiMang.java`: Tính tổng hai mảng theo từng vị trí.
- `Slide2_NhapMangTuChuoi.java`: Nhập mảng từ một dòng, đếm phần tử và tính tổng.
- `Slide3_Bai1_DuongThang.java`: Lớp điểm, đường thẳng và tính độ dài.
- `Slide3_Bai2_CacHinh.java`: Tính chu vi, diện tích tam giác, chữ nhật và hình tròn.

## Chạy chương trình

Cài JDK, mở terminal tại thư mục này và biên dịch:

```sh
javac -encoding UTF-8 *.java
```

Chạy bài cần xem, ví dụ:

```sh
java Slide3_Bai1_DuongThang
java Slide3_Bai2_CacHinh
```
